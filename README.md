# Teaching Portfolio · 独立优化版

此文件夹由原 `site/` 独立复制后调整。原 `site/`、`handoff/` 和两个原始压缩包未改动。

## 如何查看

双击本目录的 `index.html` 即可打开。六个页面及图片都使用相对路径，可整体复制或压缩分享。字体需要联网；离线时使用系统字体。

本次提供的本机预览地址：http://127.0.0.1:8766/index.html 。本机预览服务结束后，仍可双击 HTML 打开。

## 本版调整

- 保留米白纸感、栗红、衬线标题、中文印章、经历卡片和拍立得照片墙。
- 修复手机导航被挤压与展开错位，支持 Escape 收起和页面跳转后重置状态。
- 清除照片默认边距，统一尺寸和留白；手机合影使用横幅，完整显示所有人物。
- 子页使用文字与照片分区，调整裁切，减少标题遮住人脸；首页去除叠加的人像背景。
- 首页介绍更简练，手机先显示姓名、身份与入口，随后显示肖像。
- 明确活动材料及视频的进度，取消没有实际视频的播放按钮。
- 修正论文指代、自然度较低的英文与无法从照片确认的具体情境。
- 降低倾斜、磁吸动效幅度，补充照片放大的键盘操作与焦点恢复。
